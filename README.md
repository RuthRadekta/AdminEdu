# AdminEdu
Website untuk admin mengelola data mahasiswa

## Stacks
Front-end: CSS, Bootstrap, HTML
Back-end: PHP (Native), Javascript
Database: SQL

## Features
1. CRUD: Dimana admin dapat menambahkan, mengupdate, dan menghapus data mahasiswa
2. Monitoring: Admin dapat melakukan monitoring dalam dashboard admin
3. Integrasi Data: Database terhubung dengan SQL (localhost) sehingga lebih aman
4. UI/UX yang interaktif dan memudahkan pengguna
